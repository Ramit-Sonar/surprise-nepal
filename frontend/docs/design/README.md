# Surprise Nepal design documentation

This folder contains the curated design material retained from the original
frontend imports. These files are documentation only and are not bundled by
the application.

## Briefs

- `product-brief.md` — original product, responsive, and accessibility brief.
- `manual-qr-payment.md` — manual QR payment workflow requirements.
- `visual-design-brief.md` — neo-morphic visual design direction.

## References

`references/` contains representative customer and admin screens with
descriptive filenames. Iterative crops, duplicate exports, and obsolete browser
captures were intentionally removed.

## Brand source

`brand/gift-box-logo-source.png` is the retained high-resolution source image.
The application continues to use the optimized runtime asset at
`src/assets/logo.webp`.
